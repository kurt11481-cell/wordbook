# 영어 단어장 웹 앱

모르는 영어 단어를 입력하면 뜻 정보를 보여 주고, 외운 단어는 뒤로 밀어 주는 개인 단어장입니다.
가족·친구·동료 몇 명에게 링크로 나눠 쓰는 것을 목표로 합니다.

## 기능 (사용자 요청 기준)

1. 단어 입력
2. 동의어·반의어 보여 주기
3. 예문 보여 주기
4. 발음 기호와 발음 듣기
5. 품사별 정보 (명사·형용사·부사 등)
6. 체크한 단어는 우선순위가 뒤로 밀림

## 정해진 것

| 항목 | 결정 |
|---|---|
| 앱 종류 | 웹 앱 (설치 없이 링크로 사용) |
| 사용 대상 | 소수 지인 |
| 목적 | 영어 단어장 |

## 아직 정할 것 (확인 필요)

- 단어 정보를 어디서 가져올지: 무료 사전 API 후보가 있으나 동의어·예문이 모든 단어에 다 나오는지 확인 필요
- 단어장 저장 방식: 기기별 저장(로그인 없음)으로 시작할지, 여러 기기에서 같이 보이게 할지
- 뜻을 한국어로도 보여 줄지
- 사용 기술(프레임워크)과 배포 방법
