# 영어 단어장 웹 앱

모르는 영어 단어를 입력하면 뜻 정보를 보여 주고, 외운 단어는 뒤로 밀어 주는 개인 단어장입니다.
가족·친구·동료 몇 명에게 링크로 나눠 쓰는 것을 목표로 합니다.

## 기능 (사용자 요청 기준)

1. 단어 입력
2. 동의어·반의어 보여 주기
3. 예문 보여 주기
4. 발음 기호와 발음 듣기
5. 품사별 정보 (명사·형용사·부사 등)
6. 체크한 단어는 우선순위가 뒤로 밀림

## 정해진 것

| 항목 | 결정 |

| 앱 종류 | 웹 앱 (설치 없이 링크로 사용) |
| 사용 대상 | 소수 지인 |
| 목적 | 영어 단어장 |
| 저장 방식 | 구글 로그인하면 계정에 저장되어 휴대폰·PC 공유 (2026-10-28 변경). 로그인 안 하면 그 기기에만 저장 |
| 한국어 뜻 | 영어 정보와 함께 한국어 뜻도 표시 |

## 단어 정보 출처 (후보, 2026-10-28 "happy"로 시험)

- 영어 사전: Free Dictionary API (api.dictionaryapi.dev), 무료·가입 없음
  - 발음 듣기(mp3), 품사별 뜻, 동의어 13개·반의어 16개·예문 4개(형용사) 받아옴
  - 품사에 따라 동의어·예문이 비어 있는 경우 있음, 단어별 편차는 확인 필요
- 한국어 뜻 (1순위): 위키낱말사전(en.wiktionary.org) 번역표, 무료·가입 없음
  - 품사·뜻별 한국어가 나옴. 예) run → 달리다, 뛰다 / 맡다 / 흐르다 / 작동하다
  - 번역표가 없는 단어(예: ubiquitous)도 있음
- 한국어 뜻 (대체): MyMemory 자동 번역 → "행복해요"처럼 부정확할 수 있어 화면에 "자동 번역" 표시. 하루 무료 한도 확인 필요
- 영어 사전 서버가 가끔 오류(500, 연결 실패)를 내서 자동으로 두 번까지 다시 시도한다.

## 사용 기술과 배포

- 기본 웹 기술(HTML·CSS·JavaScript)만 사용, 설치할 도구 없음
- 배포: GitHub Pages (무료) → https://kurt11481-cell.github.io/wordbook/
  - 저장소: https://github.com/kurt11481-cell/wordbook (공개)
  - 고친 내용을 반영하려면 커밋 후 `git push`. 1~2분 뒤 링크에 반영된다.

## 휴대폰·PC 공유 (Firebase)

- Firebase 프로젝트: English Wordbook (`english-wordbook-e1f1f`), 무료 Spark 요금제
  - Authentication: Google 로그인 사용, 승인된 도메인에 `kurt11481-cell.github.io` 추가
  - Firestore: Standard, 서울(asia-northeast3), 보안 규칙은 `firestore.rules` 내용을 콘솔에 붙여넣어 게시
- 저장 위치: `users/{구글 계정 uid}/words/{단어}`. 각자 자기 단어장만 읽고 쓸 수 있다.
- 처음 로그인하면 그 기기에만 있던 단어를 계정으로 올린다. 같은 단어는 "외웠어요" 횟수가 많은 쪽을 남긴다.
- 로그아웃하면 그 기기의 사본을 지운다. 다시 로그인하면 계정에서 돌아온다.
- 설정값은 `firebase-config.js`. 비밀값이 아니며 데이터 보호는 보안 규칙이 맡는다.

## 우선순위 규칙

- "✔ 외웠어요"를 누른 횟수가 적은 단어가 위에 온다.
- 횟수가 같으면 더 오래전에 체크한 단어(또는 아직 체크 안 한 단어)가 위에 온다.

## 내 PC에서 실행해 보기

```
python -m http.server 8123
```

이 폴더에서 위 명령을 실행한 뒤 브라우저에서 http://localhost:8123 을 연다.
