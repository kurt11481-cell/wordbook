# 영어 단어장 웹 앱

모르는 영어 단어를 입력하면 뜻 정보를 보여 주고, 외운 단어는 뒤로 밀어 주는 개인 단어장입니다.
가족·친구·동료 몇 명에게 링크로 나눠 쓰는 것을 목표로 합니다.

## 기능 (사용자 요청 기준)

1. 단어 입력
2. 동의어·반의어 보여 주기
3. 예문 보여 주기
4. 발음 기호와 발음 듣기
5. 품사별 정보 (명사·형용사·부사 등)
6. 체크한 단어는 우선순위가 뒤로 밀림

## 정해진 것

| 항목 | 결정 |
|---|---|
| 앱 종류 | 웹 앱 (설치 없이 링크로 사용) |
| 사용 대상 | 소수 지인 |
| 목적 | 영어 단어장 |
| 저장 방식 | 각자 자기 휴대폰·PC(브라우저)에 저장, 로그인 없음 |
| 한국어 뜻 | 영어 정보와 함께 한국어 뜻도 표시 |

## 단어 정보 출처 (후보, 2026-10-28 "happy"로 시험)

- 영어 사전: Free Dictionary API (api.dictionaryapi.dev), 무료·가입 없음
  - 발음 듣기(mp3), 품사별 뜻, 동의어 13개·반의어 16개·예문 4개(형용사) 받아옴
  - 품사에 따라 동의어·예문이 비어 있는 경우 있음, 단어별 편차는 확인 필요
